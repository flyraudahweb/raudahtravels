## 2. Tables

### 2.1 `profiles`

User profile data, auto-created on signup via trigger.

| Column                  | Type        | Notes                                           |
| ----------------------- | ----------- | ----------------------------------------------- |
| `id`                  | UUID PK     | References `auth.users(id)` ON DELETE CASCADE |
| `full_name`           | TEXT        |                                                 |
| `email`               | TEXT        |                                                 |
| `phone`               | TEXT        |                                                 |
| `avatar_url`          | TEXT        |                                                 |
| `language_preference` | TEXT        | Default `'en'`                                |
| `created_at`          | TIMESTAMPTZ |                                                 |
| `updated_at`          | TIMESTAMPTZ | Auto-updated via trigger                        |

**RLS:** Users see/edit own; Admins see all.

---

### 2.2 `user_roles`

Maps users to roles. A user can have multiple roles.

| Column      | Type         | Notes                         |
| ----------- | ------------ | ----------------------------- |
| `id`      | UUID PK      |                               |
| `user_id` | UUID         | References `auth.users(id)` |
| `role`    | `app_role` | Default `'user'`            |

**RLS:** Users see own roles; Admins manage all.

### 2.3 `packages`

| Column               | Type                 | Notes                                     |
| -------------------- | -------------------- | ----------------------------------------- |
| `id`               | UUID PK              |                                           |
| `name`             | TEXT                 |                                           |
| `type`             | `package_type`     | `hajj` or `umrah`                     |
| `category`         | `package_category` | `premium`, `standard`, `budget`     |

| `currency`         | TEXT                 | Default `'NGN'`                         |
| `agent_discount`   | NUMERIC              | Default `0`                             |
| `deposit_allowed`  | BOOLEAN              |                                           |
| `minimum_deposit`  | NUMERIC              | Nullable                                  |
| `capacity`         | INTEGER              | Total slots                               |
| `available`        | INTEGER              | Remaining slots (auto-managed by trigger) |
| `inclusions`       | TEXT[]               | List of included services                 |
| `airlines`         | TEXT[]               |                                           |
| `departure_cities` | TEXT[]               |                                           |
| `duration`         | TEXT                 | e.g.,`"18 days"`                        |
| `description`      | TEXT                 |                                           |
| `image_url`        | TEXT                 |                                           |
| `status`           | `package_status`   | Default `'draft'`                       |
| `featured`         | BOOLEAN              |                                           |
| `created_at`       | TIMESTAMPTZ          |                                           |
| `updated_at`       | TIMESTAMPTZ          |                                           |

**RLS:** Anyone can view active packages; Admins manage all.
